# 리소스 파일 검사기 (Resource Checker)

3Dmigoto 모드 폴더를 열었을 때 `.ini` 파일에 명시된 모든 `filename = ...` 구문의 파일명과 확장자가 실제 디스크에 존재하는지 실시간으로 검사하는 공식 내장 플러그인입니다.

## 주요 기능

1. **실시간 에디터 린트 경고**
   - 모드 폴더를 열고 `.ini` 파일을 작성할 때, `filename = Textures/Diffuse.dds` 등 대상 파일이 실제로 존재하지 않으면 에디터에 즉시 노란색 밑줄 경고를 띄웁니다.
   - 상태 표시줄의 문제 목록에 포함되어 원클릭으로 해당 줄로 점프할 수 있습니다.

2. **사이드바 리소스 검사기 패널**
   - 현재 문서에 선언된 모든 리소스 파일 목록과 존재 여부(존재함/누락)를 한눈에 볼 수 있습니다.
   - 항목 클릭 시 해당 줄로 즉시 이동합니다.
