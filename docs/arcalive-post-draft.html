3DMigoto / XXMI 모드 INI 전용 에디터 'Migoto Studio' 배포 및 안내 (웹/무설치 지원)

작성자: DPN · 대상: 원신 / 스타레일 / 젠레스 모더 및 INI 수정 유저

안녕하세요.
3DMigoto 기반 게임(원신, 붕괴 스타레일, 젠레스 존 제로 등) 모드를 만들거나 기존 모드의 ini를 수정할 때 사용할 수 있는 전용 에디터인 Migoto Studio를 배포합니다.

모드 ini를 메모장이나 일반 텍스트 편집기로 수정하다 보면 닫히지 않은 if/endif, 오타, [ 대괄호 누락, 누락된 리소스 경로 등으로 인해 게임이 튕기거나 모드가 적용되지 않는 일이 자주 발생합니다.
그렇다고 무거운 VS Code를 설치하고 확장 프로그램까지 일일이 세팅하기 번거로웠던 분들을 위해, 가볍게 실행해서 바로 검증하고 편집할 수 있는 전용 스튜디오로 제작했습니다.

핵심 요약
- 설치 없이 웹 브라우저에서 바로 사용 가능 (인스톨러 및 무설치 포터블 zip도 제공)
- 3DMigoto 문법 실시간 오류 감지(린트)로 닫히지 않은 if문, 중복 섹션, 오타 즉시 표시
- 수천 줄 ini에서도 F12로 변수/섹션 선언부 즉시 이동, Shift+F12로 사용 위치 목록 검색
- 열린 모드 폴더 전체 검색 및 바꾸기(Ctrl+Shift+F) 지원
- 자체 내장 DDS 텍스처 뷰어 (BC7, BC1~5 포맷 에디터 내 즉시 확인)

주요 기능 안내

1. 실시간 문법 검사 (Linter)

닫히지 않은 if/endif, 누락된 대괄호, 중복 정의된 섹션, 오타를 실시간 빨간 줄로 알려주며 F7 키로 다음 오류 위치를 바로 찾아갑니다.

2. XXMI 네임스페이스 완벽 지원

모드 폴더 내 모든 INI를 자동 색인하여 다른 파일에 선언된 $\Namespace\Var 변수나 CommandList 호출을 오경고 없이 정상 인식합니다.

3. 선언부 이동 (F12) & 참조 검색 (Shift+F12)

변수나 [Section]에 커서를 두고 F12를 누르면 선언된 줄로 즉시 점프하며, Shift+F12로 해당 항목이 사용된 모든 줄을 모달 창으로 조회합니다.

4. 전체 파일 검색/치환 (Ctrl+Shift+F)

VS Code처럼 액티비티 바의 돋보기 버튼이나 단축키로 폴더 내 모든 파일과 열린 탭에서 단어/정규식 검색 및 일괄 바꾸기가 가능합니다.

5. INI 섹션 단위 코드 접기 (Folding)

방대한 길이의 INI 파일도 [Section] 단위 또는 if 조건문 단위로 깔끔하게 접어서 원하는 부분만 집중해서 수정할 수 있습니다.

6. 내장 DDS 텍스처 뷰어

외부 프로그램을 열 필요 없이 에디터 안에서 BC7(모드 0~7), BC1~BC5 규격의 DDS 및 PNG 이미지를 체커보드 캔버스로 즉시 확인합니다.

7. 스마트 자동완성 & 템플릿 패널

$ 입력 시 변수 목록, run = 입력 시 CommandList 추천, 키 토글 및 섹션 템플릿을 클릭 한 번으로 자동 완성합니다.

8. 안전한 자동 백업 및 복원

저장할 때마다 앱 데이터 폴더에 자동으로 이전 버전이 백업되므로, 실수로 코드를 날려도 '백업에서 복원'으로 되돌릴 수 있습니다.

실행 환경 및 다운로드

프로그램은 환경에 맞게 3가지 방법 중 편한 방식으로 사용할 수 있습니다.

1. 웹 버전 (설치 불필요)

웹 브라우저(Chrome, Edge 등)에서 바로 열어서 파일이나 폴더를 불러와 작업할 수 있습니다.
링크: https://dpn-dpn.github.io/migoto-studio/


2. 윈도우 무설치 포터블 버전 (.zip)

압축만 풀어서 원하는 위치에 두고 바로 실행할 수 있는 버전입니다. (프로그램 폴더 내 data/ 폴더에 설정과 백업이 보관됩니다.)
다운로드: GitHub Releases (Migoto-Studio_..._portable-x64.zip)


3. 윈도우 설치형 프로그램 (.exe)

시작 메뉴 등록 및 자동 업데이트 기능을 지원하는 인스톨러 버전입니다.
다운로드: GitHub Releases (Migoto.Studio_..._x64-setup.exe)

자주 쓰는 유용한 단축키

  • Ctrl + Shift + F : 열린 파일 및 탐색기 전체에서 텍스트 검색 / 일괄 바꾸기
  • F12 : 커서가 위치한 변수($var) 또는 [Section]의 선언 줄로 바로 이동
  • Shift + F12 : 해당 변수 또는 섹션이 사용된 모든 위치 검색 모달 열기
  • Ctrl + Shift + O : 모드 폴더 전체 열기
  • Ctrl + Shift + E : 좌측 파일 트리 탐색기 열기
  • Ctrl + B : 사이드바 보이기 / 숨기기
  • F7 : 다음 문법 오류 / 경고 위치로 점프
  • F1 : 전체 단축키 안내 및 정보 도움말 열기
